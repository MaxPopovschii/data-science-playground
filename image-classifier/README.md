# Image Classifier (CNN)

Classificatore di immagini con rete neurale convoluzionale (CNN) su CIFAR-10. Notebook completo e facilmente adattabile a dataset personalizzati.

## Struttura
- `data/`: per dataset immagini personalizzati.
- `notebooks/`: notebook Jupyter per training, valutazione e visualizzazione.

## Come usare
1. Apri il notebook in `notebooks/image-classifier-cnn.ipynb`.
2. Installa le dipendenze richieste (automatico in VS Code).
3. Segui le celle per caricare dati, costruire la CNN, addestrare e valutare.

## Requisiti
- Python 3.8+
- tensorflow, keras, numpy, matplotlib, scikit-learn

## Estensioni
- Prova altri dataset (MNIST, immagini personali)
- Modifica l'architettura della CNN
