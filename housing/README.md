# Housing Price Prediction

Questo progetto utilizza un dataset di prezzi delle case (es. Kaggle House Prices) per predire il valore di vendita degli immobili.

## Struttura del progetto
- `notebooks/` — Jupyter notebook per esplorazione, analisi e modellazione
- `data/` — Dati raw e preprocessati
- `src/` — Script Python per preprocessing, training e valutazione
- `README.md` — Descrizione del progetto

## Obiettivi
- Analisi esplorativa dei dati
- Preprocessing e feature engineering
- Addestramento di modelli di regressione
- Valutazione delle performance

## Link utili
- [Competizione Kaggle House Prices](https://www.kaggle.com/c/house-prices-advanced-regression-techniques)

## Come iniziare
1. Scarica i dati da Kaggle e inseriscili nella cartella `data/`
2. Avvia i notebook per esplorare e modellare i dati
3. Consulta gli script in `src/` per pipeline automatizzate
