# Data Science Playground

Questa repository contiene una raccolta di progetti di data science e machine learning, ciascuno organizzato in una propria cartella con notebook, dati e script.

## Progetti inclusi

- **Weather Forecast**: Analisi e previsione di serie temporali meteo con ARIMA, RandomForest e dashboard finale. Dataset di esempio: `weather-forecast/data/weather.csv`.
- **Image Classifier (CNN)**: Classificatore di immagini con rete neurale convoluzionale (CNN) su CIFAR-10. Notebook completo in `image-classifier/notebooks/image-classifier-cnn.ipynb`.
- **Altri progetti**: Puoi aggiungere altri progetti di data science (es. Titanic, housing price, anomaly detection) seguendo la stessa struttura.

## Struttura delle cartelle

```
/workspaces/data-science-playground/
├── weather-forecast/
│   ├── data/
│   └── notebooks/
├── image-classifier/
│   ├── data/
│   └── notebooks/
└── README.md
```

## Come usare i notebook

1. Apri il notebook desiderato nella cartella `notebooks` del progetto.
2. Installa le dipendenze richieste (verranno installate automaticamente se usi VS Code).
3. Segui le istruzioni e le celle del notebook per eseguire analisi, training e visualizzazioni.

## Requisiti

- Python 3.8+
- Jupyter Notebook
- Pacchetti principali: pandas, numpy, matplotlib, seaborn, scikit-learn, statsmodels, tensorflow, keras

## Suggerimenti

- Puoi aggiungere nuovi dataset nella cartella `data` di ciascun progetto.
- Personalizza i notebook per i tuoi esperimenti e confronti tra modelli.
- Per problemi o richieste, apri una issue o contatta il maintainer.
