# Weather Forecast

Questo progetto si occupa di analisi e previsione di serie temporali meteo usando modelli ARIMA e RandomForest, con dashboard finale.

## Struttura
- `data/`: contiene i dataset meteo (es. `weather.csv`).
- `notebooks/`: notebook Jupyter per analisi, feature engineering, training e visualizzazione.

## Come usare
1. Apri il notebook in `notebooks/weather-forecast.ipynb`.
2. Installa le dipendenze richieste (automatico in VS Code).
3. Segui le celle per caricare i dati, analizzare, addestrare e visualizzare i risultati.

## Requisiti
- Python 3.8+
- pandas, numpy, matplotlib, seaborn, scikit-learn, statsmodels

## Estensioni
- Prova altri modelli (Prophet, LSTM)
- Aggiungi nuovi dataset meteo
